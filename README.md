# Photoshop ArmenSakanian

Веб-приложение для лабораторных работ по технологиям компьютерной графики.

## Возможности первой лабораторной

- загрузка PNG, JPG, JPEG и GB7
- сохранение PNG, JPG, JPEG и GB7
- собственное декодирование и кодирование GB7
- отображение ширины, высоты и глубины цвета
- работа с маленькими и большими тестовыми изображениями
- адаптивный интерфейс

## Запуск

```bash
npm install
npm run dev
```

## Сборка

```bash
npm run build
```
